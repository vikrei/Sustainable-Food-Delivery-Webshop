# FRAM

Student project created for PRO1001.

## Project Description

FRAM is a responsive web application for a fresh food delivery service. The designs were provided by my institution in Figma.

---

## Features

* Responsive design for desktop and mobile devices
* Landing page with product information
* Products catalogue
* Interactive chatbot
* Newsletter subscription form with validation
* Google Maps integration
* External API integration using DummyJSON

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GitHub
* Google Maps Embed API
* DummyJSON API

---

## Setup Instructions

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html` with Live Server.
5. Navigate between pages using the website navigation menu.

---

## Usage Guide

### Home Page

Users can learn about the FRAM service and browse featured products.

### Products Page

Users can view available products and learn about partnering farms.

### Chatbot Page

Users can ask questions about:

* order
* delivery
* farm
* container
* reuse
* product

Type **help** in the chatbot to view available commands.

---

## API Limitations

The chatbot uses the DummyJSON API for demonstration purposes. The data returned by the API may not match the products displayed on the website. The API may also become unavailable or return outdated information.
